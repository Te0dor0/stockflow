# StockFlow – Sistema de Gestão de Estoque e Vendas

![GitHub License](https://img.shields.io/github/license/Te0dor0/stockflow?style=flat-square)
![GitHub stars](https://img.shields.io/github/stars/Te0dor0/stockflow?style=flat-square)
![GitHub forks](https://img.shields.io/github/forks/Te0dor0/stockflow?style=flat-square)

O **StockFlow** é uma solução completa para gestão comercial, desenvolvida para auxiliar pequenas e médias empresas no controle rigoroso de estoque, vendas e clientes. Com uma interface moderna e intuitiva, o sistema oferece ferramentas poderosas para otimizar processos e fornecer insights valiosos sobre a saúde do negócio.

---

## 🚀 Funcionalidades Principais

| Módulo | Descrição |
| :--- | :--- |
| **Dashboard Inteligente** | Visão geral com KPIs em tempo real, gráficos de faturamento e produtos mais vendidos. |
| **PDV (Ponto de Venda)** | Interface ágil para registro de vendas com baixa automática de estoque e emissão de recibos. |
| **Gestão de Estoque** | Controle detalhado de entradas e saídas, histórico de movimentações e alertas de estoque baixo. |
| **Catálogo de Produtos** | Cadastro completo com categorização, preços de custo/venda e controle de status. |
| **Gestão de Clientes** | Base de dados centralizada para acompanhamento de histórico de compras e fidelização. |
| **Relatórios Avançados** | Análise financeira mensal, desempenho por categoria e relatórios de auditoria. |

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web:

- **Frontend:** HTML5, CSS3 (Variáveis Modernas), JavaScript (ES6+).
- **Gráficos:** [Chart.js](https://www.chartjs.org/) para visualização de dados.
- **Design:** UI/UX focado em produtividade com fontes Syne e DM Sans.
- **Arquitetura:** Separação clara de responsabilidades (HTML/CSS/JS) para fácil manutenção.
